Beta — Gestão de Viagens e Reservas
Sobre o projeto

O Beta é um aplicativo Android desenvolvido para auxiliar a VaideBeta na organização de viagens e reservas.

Destinado ao uso administrativo de Betânia, o sistema centraliza informações sobre viagens, ônibus, passageiros, assentos e pagamentos, substituindo parte do controle manual por uma solução digital mais simples e organizada.

Problema

O controle manual pode dificultar o gerenciamento de passageiros, assentos e pagamentos, principalmente em viagens com muitos passageiros ou mais de um ônibus.

Alterações e cancelamentos também podem gerar informações desatualizadas e aumentar a possibilidade de erros.

O Beta busca solucionar esse problema centralizando os dados das viagens e facilitando sua consulta e atualização.

Funcionalidades

O aplicativo permite:

Cadastrar e consultar viagens;
Informar destino e data;
Selecionar os ônibus utilizados;
Visualizar a disposição dos assentos;
Cadastrar passageiros;
Associar passageiros a ônibus e assentos;
Consultar assentos ocupados;
Registrar pagamentos como Pago ou Pendente;
Editar informações dos passageiros;
Cancelar ou remover reservas.

O sistema é destinado exclusivamente ao uso administrativo da VaideBeta. Os passageiros não utilizam o aplicativo diretamente e não são realizados pagamentos pelo sistema.

Tecnologias utilizadas
Kotlin — linguagem de programação;
Android Studio — ambiente de desenvolvimento;
Jetpack Compose — desenvolvimento da interface;
Room — persistência dos dados;
SQLite — banco de dados utilizado pelo Room;
Git e GitHub — controle de versão e colaboração.
Armazenamento dos dados

O aplicativo utiliza o Room Database para armazenar localmente informações de viagens, passageiros, reservas, assentos e pagamentos.

As plantas dos ônibus são representadas por imagens incluídas nos recursos do aplicativo.

Como executar o projeto
Requisitos
Android Studio;
JDK compatível com o projeto;
Android SDK;
Emulador ou dispositivo Android.
Execução
Clone o repositório do projeto.
Abra o projeto no Android Studio.
Aguarde a sincronização do Gradle.
Inicie um emulador ou conecte um dispositivo Android.
Execute o projeto pelo botão Run.
