Beta — Gestão de Viagens e Reservas
Sobre o projeto

O Beta é um aplicativo Android desenvolvido para auxiliar a VaideBeta na organização de viagens e reservas.

O sistema é destinado ao uso administrativo de Betânia e centraliza informações sobre viagens, ônibus, passageiros, assentos e pagamentos, substituindo parte do controle manual por uma solução digital mais simples e organizada.

Problema

O controle manual pode dificultar o gerenciamento de passageiros, assentos e pagamentos, principalmente em viagens com muitos passageiros ou mais de um ônibus.

O Beta busca solucionar esse problema centralizando os dados das viagens e facilitando sua consulta e atualização.

Funcionalidades
Cadastro e consulta de viagens;
Definição de destino e data;
Seleção dos ônibus utilizados;
Visualização dos assentos;
Cadastro de passageiros;
Associação de passageiros a ônibus e assentos;
Consulta de assentos ocupados;
Registro de pagamento como Pago ou Pendente;
Edição de informações dos passageiros;
Cancelamento e remoção de reservas.
O aplicativo é destinado exclusivamente ao uso administrativo da VaideBeta. Os passageiros não utilizam o sistema diretamente e o aplicativo não realiza pagamentos.
Tecnologias
Kotlin — linguagem de programação;
Android Studio — ambiente de desenvolvimento;
Jetpack Compose — desenvolvimento da interface;
Room — persistência dos dados;
SQLite — banco de dados utilizado pelo Room;
Git e GitHub — controle de versão e colaboração.
Armazenamento

O aplicativo utiliza o Room Database para armazenar localmente informações de:

Viagens;
Passageiros;
Reservas;
Assentos;
Situação dos pagamentos.

As plantas dos ônibus são representadas por imagens incluídas nos recursos do aplicativo.

Como executar
Requisitos
Android Studio;
JDK compatível com a versão do projeto;
Android SDK;
Emulador Android ou dispositivo físico.
Passos
Clone o repositório:
   git clone URL_DO_REPOSITORIO

Abra o projeto no Android Studio.
Aguarde a sincronização do Gradle.
Inicie um emulador ou conecte um dispositivo Android.
Execute o projeto pelo botão Run.
